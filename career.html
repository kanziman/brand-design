01. 글로벌 콘텐츠 플랫폼 개발·운영

(주)아크로퓨처 · 2025.06–현재 · Kotlin / Spring Boot / Kubernetes

역할과 과제

국내 자동차 대기업의 글로벌 콘텐츠 플랫폼 백엔드 개발·운영을 담당했습니다. 국가별 공급사와 데이터 수집 방식이 다른 환경에서 남미·일본 시장의 파이프라인을 확장하고, 5개 글로벌 리전의 운영 상태를 점검하는 도구를 개발했습니다.

기술적 판단과 구현

데이터 특성에 따라 정적·동적·Push 수집 채널을 분리 설계하고 SA Collector를 도입했습니다. 헥사고날 구조로 국가별 공급사 확장에 대응하고, 다중 인스턴스의 수집기 중복 실행은 ShedLock 기반 분산 락으로 방지했습니다.

로컬 kubectl과 AWS 자격증명으로 북미·유럽·아태·일본·남미의 로그·지표·Pod 현황을 통합 조회하는 경량 관제 도구를 자체 개발했습니다. 수집 실패 시 웹에서 Lambda 기반 수집 함수를 직접 재실행해 콘텐츠 공급사(CP)의 상태를 확인할 수 있도록 구현했습니다. 오류 사례를 기록하고 이를 LLM에 질의해 장애 대응 방안을 추천받는 기능을 추가했습니다. OpenTelemetry·LGTM 분산 추적 환경에서 장애 원인을 분석하고, 확인 항목과 대응 절차를 장애 대응 플레이북으로 문서화했습니다.

성과

남미·일본 시장 수집 파이프라인을 확장하고 다중 인스턴스의 스케줄링 정합성을 확보했습니다. 리전별 운영 정보 조회를 통합하고, 실패한 수집의 재시도와 LLM 기반 대응 추천을 연결해 운영자가 상태 확인부터 재시도, 대응 방안 검토까지 수행할 수 있도록 구성했습니다. 장애 진단·점검 절차를 정리해 반복적인 운영 점검을 효율화했습니다.

02. 엔터프라이즈 어드민 및 API 연동

(주)아크로퓨처 · 메인 백엔드 / 대외사업 대시보드 PM

칩 테스트 어드민

국내 반도체 대기업의 칩 테스트 어드민 웹앱에서 메인 백엔드를 담당했습니다. Lot/Chip 단위 동시성 제어로 대용량 계측 결과의 병렬 매핑 정합성을 확보하고 매핑 사이클을 50% 단축했습니다.

이종 물리 계측 장비 연동은 자체 엔진 개발 대신 검증된 Jenkins 커스텀 연동을 선택해 초기 안정성과 납기 일정을 고려했습니다. SSE 스트리밍과 Reconnection ID 기반 세션 복구를 구현했습니다.

파트너 API 연동 지원

국내 자동차 대기업 대외사업 어드민 대시보드에서 PM과 메인 백엔드를 맡았습니다. 파트너사가 웹에서 API를 직접 호출·검증하는 샌드박스를 기획·구축하고, OAS 규격 표준화와 API Key·인증/인가·유량 제어를 설계했습니다.

운영 자동화

EV 충전소·충전기 데이터의 월별 변경 검증을 AI 에이전트로 자동화해 소요 시간을 2~3시간에서 30분으로 단축했습니다. 중요 판단은 사람이 승인하도록 구성하고, 매일 30분 소요되던 수동 점검도 자동화했습니다.

03. 사내 위키 검색 시스템 제안·도입

사내 업무 프로젝트 · 문제 정의 / 제안 / 설계 / 구현 / 도입 전담

문제와 역할

팀원들이 여러 프로젝트에 교차 투입되는 환경에서 프로젝트별 사양서의 변경 사항을 관리하고 업무 맥락을 전달해야 했습니다. 고객사에 납품했던 사양서 기반 RAG 개발 경험을 바탕으로 위키를 결합한 검색 시스템을 제안하고, 설계·구현부터 사내 플랫폼 도입까지 전담했습니다.

구현과 결과

사양서 기반 검색에 위키를 결합해 프로젝트 진행 중 갱신되는 업무 지식을 검색에 활용하도록 구성했습니다. 프로젝트 운영에서 발견한 공통 문제를 사내 시스템 도입으로 연결했습니다.

04. 금융 데이터 분산 수집 인프라

인포텍코퍼레이션(주) · 2020.08–2023.05 · Java / Spring / Redis / HikariCP

역할과 규모

일 100만 건 규모의 금융 데이터 수집 인프라를 개발·최적화했습니다. 자사 스크래핑 솔루션을 활용해 일 100~200개 금융사·기업을 대상으로 분산 수집 구조를 설계했습니다.

병목 진단과 설계

쓰기 부하 집중에 따른 DB 커넥션 고갈·잠금 경합을 규명했습니다. HikariCP 풀과 인덱스를 최적화하고 배치 쓰기를 적용해 쿼리 지연을 개선했습니다.

Redis Queue 기반 분산 스케줄러를 설계·구현해 10대 이상 노드의 작업 순서와 리소스 경합을 제어하고 수집 작업을 균등 분배했습니다.

성과

DB 병목 개선과 분산 수집 안정화를 통해 수집 성공률 99.9%를 달성했습니다.

개인 프로젝트 · 2026.08–진행 중 · 설계 / 구현 / 배포

검색과 운영 통제

원문·위키 각각의 벡터·어휘 검색을 결합한 4채널 하이브리드 검색과 RRF를 구현했습니다. 검색 채널별 순위와 기여도를 확인하는 디버그 뷰어를 구축했습니다.

인용 검증 후 보정 1회·근거 목록 대체, 토큰 예산과 비용 예약·정산, 응답 중단 시 비용 예약 유지·후속 정산을 구현했습니다. 중요 문서 변경에는 사람의 승인을 적용하고, 요청 추적과 Langfuse로 처리 과정을 관측했습니다.

개발과 검증

OpenSpec 기반 SDD로 AI 에이전트 팀의 작업을 나누고 인수 조건을 공유했습니다. 리뷰어 에이전트의 병합 전 검증에서 발견된 워크스페이스 간 비용 기록 권한 결함을 수정·재검증했습니다.
